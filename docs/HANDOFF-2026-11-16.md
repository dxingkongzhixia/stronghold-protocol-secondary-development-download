## 6. 已知坑 / 注意

- **隔离是硬规则**：盟约与规程互不影响；规程行为只能由版本数据或该版本独有的 id 触发。默认数据、默认 golden、盟约数值不得因规程改动。
- **golden 归因**：改到 `test/golden/*` 必须先证明「只回退本次改动 → 零差异」，再单独提交 golden。仓库里的 `test/golden/act3autochess-v3_1/` 是规程语料。
- **不要手改 `data/*.json`**：改 `tools/build-data.mjs` 再离线重建；`data/assets.json` 由 `fetch-assets` 生成。
- `char_patch_table.json` 是规程构建的必需输入；别的机器如果只有旧的 8 表缓存，构建会报 `missing cached file`。
- `recruitTierExempt` 仍阻塞：当前 pin 无该字段。
- 本地客户端是 **LZ4AK/LZHAM** 压缩，UnityPy 直接读会失败；脚本里先 `import aklz4` 再 `UnityPy.load`。
- 技能图标纹理名是 `skill_icon_skchr_*`，导出到 `public/assets/local/skill/<skillId>/<skillId>.png`。
- Node 的 TLS 被中间证书挡住：下载 gamedata 用 PowerShell `Invoke-WebRequest`。
- 后台跑全量测试要写文件再读，前台会长时间无输出。
- 镜像脚本**不会删除** run tree 里已删除的文件，需手动删。
