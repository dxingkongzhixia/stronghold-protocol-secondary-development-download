# 插件风险说明（玩家版）

本服务器的插件不是官方内容。安装、开启或加入带插件的房间前，请先看插件类别。

## 四类插件

| 类别 | 能做什么 | 风险 | 建议 |
|---|---|---|---|
| 外观 | 换头像、立绘、模型、语音、音效、主题、公告 | 基本不改玩法，但可能改变你看到的画面/声音 | 可以按喜好开启；不喜欢就关掉 |
| 改变玩法 | 改数据、加干员、加羁绊、改规则 | 会改变本局平衡；该对局默认不计入统计总览 | 只在你信任房主和插件作者时开启 |
| 脚本沙箱 | 在受控沙箱里运行代码，注册技能/战斗逻辑 | 可能影响对局稳定性和性能；沙箱不是绝对安全边界 | 看作者、版本和锁；不要随手开陌生脚本 |
| 原生信任 | 原生代码，权限最高 | 可能完全控制你的页面或服务器进程；风险最高 | 只在你完全信任作者和服务器时同意；公网服务器默认不建议开启 |

## 房间插件和个人插件

- 房间插件：房主开启后对全房间生效
- 个人插件：只影响你自己的浏览器
- 带「改变玩法」的房间会产生独立内容集，房间顶部会显示「非官方」
- 外观插件只改变画面和声音，不会改变对局 `cs`

## 受信任插件

如果房间出现「受信任插件」提示：

1. 先看插件 id、版本、权限和作者
2. 只有在你信任作者和服务器时才点「同意并继续」
3. 拒绝不会影响你作为玩家加入，但房主不能在你未同意时开始该房间
4. 同意只对当前内容集（`cs`）有效；内容集变化后需要重新确认

## 统计

- 原版对局进入统计总览
- 带「改变玩法」插件的对局默认不计入统计总览
- 测试房间也不计入
- 这不是战绩丢失，而是避免把不同规则的对局混在一起

## 看到可疑插件怎么办

- 不要在房间里同意「原生信任」
- 关闭个人插件：设置 → 外观插件
- 退出房间，换一个没有该插件的房间
- 向服务器 owner 报告插件 id、版本、作者和现象
- owner 可以关闭 `SP_PLUGIN_SCRIPTS`，或从 `plugins/config.json` 移除对应放行

## 不要做

- 不要把官方游戏文件打包进插件
- 不要开启来源不明的「原生信任」插件
- 不要相信“导入成功 = 完全等价”的 Forge 宣传；Forge 只支持部分转换
- 不要把管理员 token、工作室钥匙或服务器文件发给别人
